# User directives (verbatim essentials, 2026-11-23) — govern ALL animation work

## A. ANIME FIGHTING GAME — COMPLETE ANIMATION IDENTITY & MOVESET OVERHAUL
Role: elite combat animator / Blender artist / animation director / fighting-game combat designer.
Use ALL existing animations as a skeletal+motion FOUNDATION; extensively modify/reconstruct/refine into distinctive, expressive, fluid, satisfying animations for EVERY power, ability and moveset. Existing animations are references, NOT finished animations to copy.

1. Use the entire library: basic attacks/punches/kicks/combos, heavy/charged/finishers, martial stances, dodges/evasions/counters/parries, aerial/launch/juggle, movement/dash/jump/land, casting/charging/releasing, hit reactions/knockbacks/recoveries, idles/combat stances, transformations/awakenings/ultimates. Do not simply retarget and call it finished.
2. Every power its own animation identity (examples, not templates — analyze every actual power): Fire = aggressive, explosive, forward-driving, strong hip rotation, ignition gestures, volatile heavies. Lightning = sharp, precise, extremely fast, sudden accel/decel, minimal motion, surgical. Gravity = deliberate, heavy, oppressive, subtle gestures with huge force, anticipation/resistance. Shadow = elusive, deceptive, unusual angles, fluid offense/evasion, unpredictable but readable. Pure martial arts = grounded, believable, proper footwork/balance/weight transfer, distinct punch/kick/grapple/counter, no needless acrobatics.
3. NO SAMEY animations: no identical punches with different VFX; no recycled casting gestures/sequences/dodges/ults across unrelated abilities. Differences required in stance, anticipation, footwork, trajectories, speed/rhythm/acceleration, body mechanics/weight, recovery, personality. Identifiable with VFX OFF. Shared rigs/infrastructure OK; final performances individually authored.
4. No pointless exaggeration (no full-body spin on a basic punch, no acrobatic simple kick, no cinematic windup on basics, no constant flips/spins/contortions) AND no boring realism (not generic realistic punches everywhere, keep anime personality, varied timing curves, refine mocap artistically). Exaggeration must be EARNED: ultimates dramatic; basics quick, purposeful, satisfying.
5. Hierarchy: Basic M1 fast/grounded/clean/responsive; M1 finisher stronger impact + distinctive follow-through; Heavy weight/anticipation/commitment; Special unique movement reflecting the power; Counter/parry precise/reactive/technical; Mobility fluid/controlled/instant; Ultimate cinematic, individually choreographed; Awakening transformative, personality-driven. Basics never more elaborate than ultimates.
6. Blender workflow per moveset: Analyze → Reference → Block (key poses, silhouettes, trajectories, footwork) → Reconstruct → Refine (timing, spacing, weight, arcs, anticipation, follow-through) → Polish (stiffness, foot slide, clipping, joints, transitions) → Integrate → Validate in real gameplay (combos, cancels, movement, hit reactions). 12 principles; smears/trails/squash-stretch/secondary motion selectively.
7. Handcrafted: each power has its own stance, basic combos, heavy choreography, specials, dodges/movement, ultimate, recovery/transitions, timing/rhythm. Same element ≠ same identity (fire swordsman ≠ fire brawler).
8. Responsiveness: immediate feedback, clear anticipation/active/recovery, hitbox sync, smooth transitions, cancel windows, consistent root motion, no foot slide/teleport/snap, no excessive locks, clean ground↔air, stable perf in big fights. Blending/additive/procedural only to improve, never instead of authoring.
9. Uniqueness audit vs every other power (silhouette, style fits power, trajectories, rhythm, needless spins, too realistic/stiff, resembles another, clear purpose per attack, convincing without VFX). Rework until distinguishable.
10. Hands-on: inspect project, implement directly, quality over quantity but no generic placeholders, preserve combat mechanics, test in-game.
DO NOT: reuse identical final animations across powers; same basic combo for every power; acrobatic ordinary attacks; lifeless realism; hide weak animation behind VFX; generic templates; quantity over quality.
Standard: every power animated as if by a dedicated professional animator who knows exactly how it fights.

## B. CRITICAL DIRECTIVE — USE PROVIDED SKYRIM HKX ANIMATIONS AS THE FOUNDATION
HKX files (Skyrim + mods) are the PRIMARY resource. Don't ignore them or create generic animations from scratch unnecessarily.
1. Extract/analyze/catalog every HKX (combat, locomotion, weapon techniques, dodges, specials, idles, transitions): keyframes, mechanics/weight, trajectories, timing/momentum, footwork/anticipation/follow-through, potential uses. Searchable library. Don't discard a clip because it doesn't match: sword footwork can serve an unarmed fighter; a dodge can found a teleport.
2. MODULAR building blocks: deconstruct, combine, modify, reconstruct into new performances (footwork from one, torso rotation from another, strike from a third; new key poses, timing, anticipation, recovery, secondary motion). Use Action Editor, NLA, Graph Editor, retargeting. Sources give fundamentals, not final choreography.
3. Distinct choreography per power even from the same source (posing, movement, timing, technique, personality). Lightning precise/abrupt/explosive; gravity deliberate/oppressive; martial believable; berserker committed momentum. Recognizable with VFX off.
4. No boring realism or pointless exaggeration (no 360 spins on basics, random flips, long windups on simple attacks, generic punches everywhere, gameplay-interrupting poses, stiff/robotic/recycled look). Intensity matches the action.
5. Pipeline: identify style → search HKX library → convert+retarget → deconstruct into components → rechoreograph → hand-refine → secondary motion + anime stylization → fix clipping/slide/joints/transitions → export+integrate → test+polish in gameplay. Verify the pipeline per HKX format.
6. PERMANENT production framework: catalog of every source; categorization by movement/technique; searchable metadata + previews; source→target retarget profiles; modular extraction/combination tools; Blender authoring templates; validation + export tools; docs mapping finished animations to sources (provenance). Preserve originals; respect mod permissions.
7. Actually implement across every power/moveset; test in-game (responsiveness, hitbox sync, transitions, cancels, quality, perf). Document any unconvertible HKX and use alternatives.
Final: no generic AI choreography, recycled attacks or lazy retargeting. HKX = skeleton of the system, Blender = production environment, pro anime combat choreography = quality standard.
